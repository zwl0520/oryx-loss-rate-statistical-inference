03 · 统计方法总览

分析框架：从数据到结论

  1. ① 模型设定 —— $Y_t \sim \text{Poisson}(\lambda)$，日均损失率建模
  2. ② MLE点估计 —— $\hat{\lambda} = \bar{Y}$，样本均值即MLE
  3. ③ 置信区间 —— Wald / Score / Exact 三方法比较 + Monte Carlo覆盖率验证
  4. ④ Block Bootstrap —— $b=11$ (ACF衰减法)，BCa偏差校正
  5. ⑤ 两样本检验 —— E-test条件精确检验 + 分层比较 + Bonferroni校正
  6. ⑥ 报告偏差 —— 声称 vs 验证对比 + 观测灵敏度分析

03 · Poisson模型与MLE点估计

模型设定

设第 $t$ 天的装备损失数为 $Y_t$，$Y_t \sim \text{Poisson}(\lambda)$，$\lambda$ 为日均损失率。

MLE推导

似然函数：$L(\lambda) = \prod_{t=1}^{n} \frac{e^{-\lambda} \lambda^{Y_t}}{Y_t!}$

结论： $\hat{\lambda}_{MLE} = \frac{1}{n}\sum_{t=1}^{n} Y_t = \bar{Y}$ ——即样本均值！

直观理解： "极大似然"就是选择使观测数据出现概率最大的参数值。Poisson分布的MLE恰好是样本均值——日均损失率的最佳估计就是"平均每天损失几件"。

03 · MLE的性质与率比推断

Fisher信息量与渐近性质

  • Fisher信息量：$I(\lambda) = n/\lambda$
  • 渐近方差：$\text{Var}(\hat{\lambda}) = \lambda/n$
  • 标准误：$\text{SE}(\hat{\lambda}) = \sqrt{\hat{\lambda}/n}$

率比 $\rho = \lambda_{RU} / \lambda_{UA}$ 的推断

  • MLE：$\hat{\rho} = \hat{\lambda}_{RU} / \hat{\lambda}_{UA}$
  • Delta方法标准误：

$$\text{SE}(\hat{\rho}) = \hat{\rho} \cdot \sqrt{\frac{1}{\hat{\lambda}_{RU} \cdot n} + \frac{1}{\hat{\lambda}_{UA} \cdot n}}$$

  • 95% Wald CI：$\hat{\rho} \pm 1.96 \cdot \text{SE}(\hat{\rho})$

03 · 三种Poisson置信区间

方法 原理 优点 缺点
Wald MLE渐近正态性 $\hat{\lambda} \pm z_{\alpha/2}\sqrt{\hat{\lambda}/n}$ 计算简单 小λ时覆盖率严重不足（λ=0.5时仅91.9%）
Score 得分统计量，解 $(\hat{\lambda}-\lambda)^2/(\lambda/n) = z^2$ 自动保证非负下限，比Wald稳健 计算略复杂
Exact ★ Poisson与χ²精确关系 (Garwood, 1936) 保证覆盖率≥名义水平 区间可能略宽

实际建议： 稀有事件（飞机λ<0.1）→ 必须用Exact CI；大样本（n=1,559）→ 三种方法几乎重合

03 · Block Bootstrap 与 BCa 校正

为什么需要Block Bootstrap？

装备损失时间序列存在强自相关：lag-1 ACF = 0.589

  • IID Bootstrap 假设观测独立 → 严重低估标准误
  • 实测：IID Bootstrap SE = 0.42，Block Bootstrap SE = 0.99（2.4倍！）

Moving Block Bootstrap 步骤

  1. 将数据分为 $n-b+1$ 个长度为 $b$ 的重叠块
  2. 有放回抽取 $k = \lceil n/b \rceil$ 个块
  3. 拼接成Bootstrap样本，计算均值
  4. 重复 $B$ 次获得Bootstrap分布

块长度选择： ACF衰减法 → $b = 11$（备选：$b = n^{1/3} \approx 12$）

03 · BCa 校正与 E-test

BCa（Bias-Corrected and Accelerated）校正

  • $ \hat{z}_0 $ (偏差校正)：$\Phi^{-1}(\#\{\hat{\theta}^*_b < \hat{\theta}\} / B)$，校正Bootstrap分布中心偏移
  • 本文 $\hat{z}_0 = 0.221$（轻微正偏）
  • $ \hat{a} $ (加速常数)：通过Jackknife估计，校正方差的非恒定性
  • 本文 $\hat{a} = 0.022$

两独立Poisson条件检验（E-test）

核心原理： 在 $H_0: \lambda_1 = \lambda_2$ 下，给定总计数 $S = Y_1 + Y_2$：

$$Y_1 \mid S \sim \text{Binomial}\left(S, \frac{n_1}{n_1 + n_2}\right)$$

  • 条件分布不依赖未知的 $\lambda$ → 直接计算精确p值
  • 本文构建4层检验结构：总体 → 装备类型(10类) → 损毁状态(4类) → 战争阶段(36对)
  • Bonferroni校正控制整体Type I错误率

04 · Block Bootstrap 实证结果

方法 块长度 Bootstrap SE 95% CI
IID Bootstrap b=1 (等价) 0.42 [13.91, 15.54]
Block Bootstrap b=11 (最优) 0.99 [12.82, 16.59]
BCa Block Bootstrap b=11 — [13.18, 17.29]

核心发现

  • 🚨 Block Bootstrap SE ≈ IID 的 2.4 倍 —— 忽略时间自相关将低估不确定性 58%！
  • BCa CI 略向右偏移（$\hat{z}_0=0.221$），反映Bootstrap分布的正偏特征
  • 块长度敏感性：$b: 1 \to 30$ 时，SE: $0.42 \to 1.28$（单调递增，$b \geq 7$ 后放缓）

04 · 观测概率偏误校正分析

核心问题： 观测到的 2.07:1 率比在多大程度上受观测偏误影响？

偏误校正框架： $\rho_{true} = \rho_{obs} \times (p_{UA} / p_{RU})$

设计： 声称数据约束下界 ($p_{RU} \geq 0.34$) + 先验嵌入 Bootstrap ($B=5000$)

假设 ($p_{RU}, p_{UA}$) 校正率比 含义
等概率 2.07 率比不变
合理先验 (Beta 均值 0.70/0.55) 1.63 (中位数) 校正后仍 >1
极端 (0.9, 0.4) 0.92 ⚠️ 率比逆转

★ P($\rho_{corrected} > 1$ | 设定的 Beta 先验) = 88.1%

结论： 2.07:1 率比在设定的观测偏误先验下具有较高稳健性；88.1% 是先验敏感性分析结果，不是仅由观测数据直接识别出的概率。

05 · 方法论启示

CI方法选择

小样本/稀有事件必须用Exact CI；大样本下三种方法等价。覆盖率保底原则至关重要。

时间依赖性的不可忽略性

IID Bootstrap低估SE约2.4倍。任何忽略时序依赖的SE估计都将严重不准。

  • 日度Block Bootstrap (b=11): SE = 0.99
  • 周度交叉验证: SE = 0.82
  • 两者均为IID (0.42) 的2–2.4倍

E-test的优势

基于精确条件分布，免于大样本渐近假设。多层比较中提供一致且可靠的推断。

多重比较

Bonferroni校正虽保守但有效。10类装备 $\alpha_B = 0.005$，控制整体Type I错误率。

05 · 主要局限性

  1. 观测偏误难精确定量： 双方观测概率的差异目前只能做方向性讨论，缺乏精确定量校正模型
  2. Poisson假设限制： 部分阶段可能存在过离散（overdispersion）和时变 $\lambda$
  3. 协变量缺失： 未纳入战线移动速度、战斗强度、天气条件等外部变量
  4. 数据口径差异： WarSpotting 与 Oryx 双方的计数口径不完全一致（部分装备子类分类差异）

未来方向

  • 🔮 贝叶斯层次模型 —— 融合多来源数据，对偏误因子显式分层建模
  • 🔮 过离散处理 —— 负二项（Negative Binomial）或广义Poisson回归
  • 🔮 时空模型 —— Hawkes自激过程或非齐次时空点过程
  • 🔮 预测模型 —— 将统计分析结果作为ARIMA/深度学习模型的输入

06 · 主要结论（一）

结论 1–4

1. 双方损失率存在极显著统计差异（p < 0.0001）

俄方日均 15.11 件/天 (CI: [14.92, 15.30])，乌方 7.31 件/天 (CI: [7.18, 7.45])，率比 2.07:1 (CI: [2.02, 2.11])

2. 偏误校正框架提供先验敏感性支持

在 $p_{RU}\sim Beta(7,3)$、$p_{UA}\sim Beta(5.5,4.5)$ 的设定下，校正后率比中位数 1.63 (95% CI: [0.67, 3.44])，$P(\rho_{corrected}>1)=88\%$

3. 双方损失比率呈现明显下降趋势

战争初期俄方验证损失显著高于乌方；近期多个窗口已接近或低于 1，排除明显负修正月后约 0.65–0.8

4. 装备类型差异显著且有战术含义

日度差分口径显示进攻型装备俄方损失约 3–4 倍；APC 是乌方反超类别之一。具体子类别数量需注明口径

06 · 主要结论（二）

结论 5–8

5. 空间分布高度集中

顿涅茨克州占45%+；最热网格 (48°N, 37°E) 单独占21.5%；战区重心从北部转移到东部

6. Exact CI 在小 λ 下是唯一可靠的选择

λ=0.5 时覆盖率 96.6%（vs Wald 91.9%）；稀有事件必须使用Exact CI

7. 时间依赖性通过两种Bootstrap交叉验证

日度Block Bootstrap SE（0.99）是IID（0.42）的2.4倍；周度（0.82）是IID的2.0倍

8. 官方声称与影像验证间存在系统性差异

主要重装备类别约 2.6–29 倍，火炮 29 倍差异最为突出；无人机等类别需单独讨论口径
